# ManyRoots

*Follow one root. See everything connected.*

An evidence-graded map of every option people actually try for a condition — herbs, foods,
minerals and nutrients, practices, and conventional medicine — each graded the same way and
each cited to the primary literature, or absent.

**Every connection is cited, or it does not appear.** There is no "traditionally believed to
support" tier with nothing behind it. Widely used things the evidence does not support stay
on the map, clearly labelled — removing them would make this a sales tool.

- **9 conditions · 200 graded connections · 139 interventions · 1,477 citations**
- **34% of citations are null or negative** — evidence that something did not work
- Nothing is sold here. No products, no affiliate links, no sponsored placements.

See `/how-we-grade` for the method, what the adversarial review actually caught, and where
it can be wrong.

## This is generated

Do not hand-edit these pages. They are built from verified condition data by the generators
in the private working directory and overwritten on every build.
